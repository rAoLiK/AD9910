## 功能细节

1. 使用conda进行环境管理，环境名称为Anal
2. 使用matplotlib进行可交互图片的绘制
3. 要求读取文件夹下的所有文件并列出可绘制的文件（在列表开始给出编号）
```
eg:
1.a
2.b
3.c
```
4. 要求可以绘制多条数据曲线，并控制哪些曲线绘制在同一张图中
5. 要求使用命令行交互，实现图片选择性保存的功能
```
# 命令示例

# 脚本输出提示（如：请选择需要绘制的数据）
# 用户输入：
[1,2][3,4,5][6] # 一共绘制三幅图，在一个括号中的绘制在同一张图中（不保存）
[1,2]{3,4,5}[6] # 一共绘制三幅图，在一个括号中的绘制在同一张图中（被{}框住的即为要保存的图片，例子中为第二张）
```
6. 要求实现成循环脚本，绘制完图片后可使用命令行关闭所有图片，紧接着进入下一轮循环（即再次列出所有文件，询问要分析的数组）
7. 要求配置刷新命令，刷新后重新读取log文件夹下的文件并重新列表


## 绘图风格

1. 深色背景，不同数组使用易于区分的颜色绘制
2. 图名为图片编号+包含的数据
3. 所有图片元素采用英文
4. 绘制的图像简洁美观
