# 功能添加说明

## 总体说明
1. 添加fft分析功能并完善命令行交互逻辑，要求可以选择多种窗函数种类（默认使用汉宁窗）
2. 添加指定图名以及标题的功能
3. 兼容之前的命令
4. 添加拼图功能（两张图生成在一个窗口中）

## 实现细节
1. 主要是对命令行命令的拓展，按照以下示例实现
```
# 命令示例

# 脚本输出提示（如：请选择需要绘制或分析的数据，列举窗函数编号）
# 用户输入：
[1;2,3][3,4|5,6]  # 一共绘制两幅图，在一个括号中的绘制在同一张图中，用“|”或“;”分开的数组生成在两张子图中（|为左右，;为上下），想办法解决两个分隔符混用的兼容。

[1,2]{f$2(1,2)@1M|f(3)@2M,f(4)@1M}[6] # 一共绘制三幅图，在一个括号中的绘制在同一张图中（被{}框住的即为要保存的图片，例子中为第二张）
# 需要fft的数组使用f$2(1,2)@1M类似的形式展现，含义是将1,2号数组的fft绘制在一幅图片中，'$2'指的是使用2号窗函数，‘@1M’指的是采用1M采样频率
# f(3)@2M,f(4)@1M 指的是使用不同采样频率的的fft绘制到同一张图中，横坐标范围取决于最高采样频率
# $与@参数可以省略，使用默认值，$默认为1 （汉宁窗）；@默认为1M
# fft点数取决于f$2(1,2)@1M中最长的数组补零到最小的2的次方点数
```
