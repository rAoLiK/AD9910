# GDB 数组可视化 + FFT 脚本（中文）

本目录提供一个交互式 Python 脚本，用于将 GDB 日志中的数组数据进行可视化绘制，并支持 FFT 分析。

## 功能

- 读取 `../log` 下所有文件（文件名即数组名）
- 从每个文件中的第一个 `{...}` 数据块提取数值数组
- 按编号列出可绘制文件
- 支持命令行分组绘图（多条曲线可绘制到同一图）
- 支持按组选择性保存图片
- 支持 FFT 分析与窗函数选择（默认汉宁窗）
- 支持在同一窗口中拼图（两子图，支持上下/左右）
- 支持自定义图窗名与图标题
- 支持鼠标悬停自动吸附最近数据点并显示坐标（缩放/平移后仍有效）
- 支持鼠标右键固定/取消固定吸附点；固定多个点时显示横坐标相邻点两两的 Δx/Δy
- 循环交互：绘图 → 关闭全部图窗 → 下一轮
- 支持 `refresh` 重新扫描 `../log`
- 深色背景、英文图形元素、风格简洁

## 输入语法

脚本会先输出可绘制数组，例如：

```text
1.a
2.b
3.c
```

你可以输入分组表达式：

- `[1,2][3,4,5][6]`：共绘制 3 张图，不保存
- `[1,2]{3,4,5}[6]`：共绘制 3 张图，其中第 2 张保存（`{...}` 组）
- `[1;2,3]`：在 1 张图中上下两子图
- `[3,4|5,6]`：在 1 张图中左右两子图
- `[1;2;3]`：在 1 张图中上下三子图
- `[1|2|3]`：在 1 张图中左右三子图
- `{f$2(1,2)@1M|f(3)@2M,f(4)@1M}`：保存该图，左右两子图执行 FFT 绘制
- `{fz$2(1,2)@1M}`：保存该图，先去直流分量再 FFT
- `[1,2]<Raw,Raw Signal>`：位置参数写法，按顺序为图窗名和图标题
- `[1,2]<name=Raw,title=Raw Signal>`：键值写法（仍兼容）

### FFT 语法

`f$<窗函数编号>(数组编号列表)@<采样率>`
`fz$<窗函数编号>(数组编号列表)@<采样率>`

- `$` 与 `@` 可省略
- 默认窗函数：`1`（Hann / 汉宁）
- 默认采样率：`1M`
- 采样率单位支持 `K`、`M`、`G`
- `fz` 表示先去直流分量（减去均值）再进行 FFT，其他逻辑与 `f` 完全一致

分隔符规则：

- 同一个分组中，顶层只能使用一种拼图分隔符（`;` 或 `|`）
- 同一分组混用顶层 `;` 和 `|` 会被判定为歧义并报错

窗函数编号：

1. Hann（默认）
2. Hamming
3. Blackman
4. Bartlett
5. Rectangular

命令：

- `refresh`：刷新并重新读取 `../log`
- `windows`：查看窗函数编号列表
- `help`：查看帮助
- `q`：退出

保存图片目录：

- `./output/<figure_name>.png`
- 若多个保存分组在文件名清洗后重名，脚本会自动追加后缀（`_2`、`_3` 等）

## GDB 日志格式示例

```text
=cmd-param-changed,param="logging enabled",value="on"
~"$4 = {0, 1, 2, 3, ...}\n"
```

脚本会从 `{}` 内提取数据并绘图。
