# 工程集成信息补充

## 继电器

- GPIO：`PE5`
- 当前定义：高电平选择输入直通，低电平选择 DDS。
- 高低电平含义必须通过宏配置，以便后续硬件修改。
- 上电及错误安全位置：输入直通。

Task5 另使用一个总输出选择继电器：

- GPIO：`PE6`
- 高电平：选择 DDS/Task1–4 输出支路。
- 低电平：选择 `PA4 / DAC_OUT1` 锯齿波支路。
- 上电、安全状态及 Task1–4 均保持高电平。
- Task5 粗识别锯齿波阶段为低电平；切换 DDS 搜索前先停止 DAC，DDS
  配置成功后再置高。Task5 错误或退出时恢复高电平。

## TJC 串口屏

- 串口：USART6。
- MCU 发送：`PC6 / USART6_TX` 接屏幕 `RX`。
- MCU 接收：`PC7 / USART6_RX` 接屏幕 `TX`。
- MCU 与屏幕必须共地；串口信号为 3.3 V TTL。
- 原 `PA9/PA10` 不再连接串口屏。
- 波特率：115200。
- 页面数字 ID：
  - `page0`：0，菜单。
  - `page1`：1，Task1-4。
  - `page2`：2，Task5。
- 所有按钮均在按下沿触发。
- 页面切换由单片机在识别按键后主动发送 `page <id>` 指令，屏幕按钮
  不自行切页。

### Page0（menu）

| 控件 | component ID |
|---|---:|
| b1 | 2 |
| b3 | 3 |

| 控件 | 功能 | component ID |

## 幅度

- AD9910 最大 ASF 时，放大后输出约为 4.2 Vpp。
- 此值必须用宏定义，允许上板后重新标定。
- ADC2 反馈点在放大器之前。
- 示波器灵敏度为 0.5 V/div；2/4/6/8 div 分别按目标
  1/2/3/4 Vpp 换算 ASF。

## 相位和任务

- Task2 只要求正交圆形，正交方向可由固件确定。
- DDS 真实输出与 ADC2 锁相反馈固定相差 180°。
- Task3 的广义相位/“∞”方向可由固件确定。
- Task4 保持最近选择的 Task1、Task2 或 Task3 图形类型，只改变幅度。

## Task5 按键

- PA0、PB9、PB8 分别映射到直线、圆和“∞”三个自动模式。
- 同一模式键短按（按住时间小于 400 ms）选择 1 kHz 锯齿波；长按
  （按住时间大于等于 400 ms）选择 10 kHz 锯齿波。
- Task5 已进入任一模式后仍可再次按键重选；STM32 停止旧 Session 并用
  新 Session 进入本次选择的锁相模式。
- 三个 EXTI 仅在 Task1–4 状态下关闭；非 Task5 状态不会消费按键去启动
  Task5 Session。

## Task5 OpenMV 与锯齿波

- OpenMV 使用 UART5：PC12/TX、PD2/RX，115200 8N1，3.3 V TTL。
- 锯齿波从 PA4/DAC_OUT1 输出，为 100 点单调递增波形。
- TIM6 TRGO 触发 DAC，DMA1 Stream5 循环搬运。
- 最终协议见 `Task5与OpenMV串口通信协议-最终版.md`。
